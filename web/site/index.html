Cybiko USB Gate

Turns a Cybiko Xtreme on its USB cable into an Internet gate (CyWIG) for the Cybikos around it, right from this page: nothing to install. Pages for the WAP browser and Browser.app, and, if you like, Chat with the people in the web emulator.

This browser has no WebUSB. Use Chrome or Edge (on a computer, or on Android with a USB OTG cable), or the cywig program.

1. Put USB Gate on the Xtreme

Copy USBGate.app to the Xtreme once (with EZ Loader, or any way you put applications on it). This page starts it by itself (but on Windows, start it on the Xtreme yourself). When it starts, the Xtreme leaves USB for a moment and comes back as "USB Gate": the first time, the page asks you to pick it again.

2. Connect

Plug the Xtreme in (CyOS on, not the boot screen) and press Connect. On Windows, start USB Gate on the Xtreme first (Windows sets it up by itself then, see below).

If Connect doesn't show the Xtreme

  • Windows (8 or newer) opens it only while USB Gate runs: start USB Gate on the Xtreme by hand, wait a few seconds while Windows sets it up (the first time), then press Connect and pick the Cybiko. USB Gate shows up as its own USB device (0B66 0042) that asks Windows for the WinUSB driver itself, so there's no driver to install. (The Xtreme without USB Gate, 0B66 0041, still needs Zadig; that's only needed to have this page start USB Gate for you.)
  • Linux: allow your user to use it, e.g. a file /etc/udev/rules.d/50-cybiko.rules with SUBSYSTEM=="usb", ATTR{idVendor}=="0b66", MODE="0666", then plug it in again.
  • Mac, ChromeOS, Android: nothing to set up.

Keep this tab open while it runs (it may be in the background).
